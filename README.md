# Commercial Image Reverse Engineer

把产品图与视觉参考转化为适合自己产品的商业静物图提示词。

这个 Skill 会分析参考画面如何通过构图、光线、材质和空间传达感受，锁定你的产品外观，再将有效的摄影方法转译为新的画面。默认中文输出，可按要求提供英文版。

## 适合用来做什么

**目前最适合一次处理一张画面：给产品、给参考、说明卖点，得到一条可用于生图的提示词。**

- **分析参考图**：理解画面的视觉焦点、光影、材质、前后景与氛围。
- **为自己的产品写提示词**：保留产品身份，结合卖点和使用体验，重新设计场景。
- **诊断生成结果**：对照原产品和要求，找到主要偏差，给出局部修复提示词。

也可以只提供产品图和明确的创意需求，由 Agent 协助构思。提供参考图通常更便于对齐审美；参考的价值是表达方法，不是必须照搬的物体和布局。

### 关于整套画面

本 Skill 当前以**单张分析与提示词生成**为核心，尚未提供完整的系列策划与跨图管理流程。做多张系列时，应先与 Agent 确认每张的卖点、景别、动作关系和共同视觉语言，再逐张调用、逐张确认。不要仅凭“做六张”就默认它会持续管理整套叙事。

## 安装与调用

### 在这个仓库中使用

1. 在 Codex 中打开本仓库。
2. 输入 `$`，查找 `commercial-image-reverse-engineer`。
3. 上传产品图与参考图，使用下面的调用示例。

Skill 入口位于 `.agents/skills/commercial-image-reverse-engineer/SKILL.md`。

### 在其他项目中使用

将本仓库的整个 `.agents/skills/commercial-image-reverse-engineer` 文件夹复制到个人 Skills 目录：


如设置了 `CODEX_HOME`，使用其下的 `skills` 目录。复制的是包含 `SKILL.md` 的技能子文件夹，而不是整个仓库。安装后在新会话中检查技能是否出现。

## 准备哪些资料

| 资料 | 用途 |
|---|---|
| 产品清晰原图 | 锁定瓶型、颜色、材质外观、部件、标签与数量 |
| 喜欢的参考图 | 对齐构图、光线、色调、景深和氛围 |
| 本张要表达的卖点或使用感受 | 决定画面为什么这样设计 |
| 画幅、用途及必须保留的细节 | 控制最终交付 |
| 开盖、背面等补充细节图（按需） | 支持主图看不到的结构 |

明确每张图的职责，例如“图1是产品，图2只参考布光和氛围，图3只补充瓶口结构”。包装字看不清时，可以直接提供准确文字。

## 最常用的调用方式

### 产品＋参考，生成单张提示词

```text
$commercial-image-reverse-engineer

图1是我的产品，图2是视觉参考。
本张重点表达：[产品卖点或使用体验]。
我喜欢参考中的：[光线、材质、氛围或构图]。
请先简要分析参考为什么成立，再提出适合我产品的画面，
确认后输出一条可直接复制的中文生图提示词。
画幅：[3:4]。必须保留：[产品关键细节]。
不要继承参考产品的瓶型、品牌或附加配件。
```

### 只分析一张参考图

```text
$commercial-image-reverse-engineer
分析这张图的焦点、前中后景、布光、材质和氛围。
总结最值得借鉴的摄影方法，先不写新画面的提示词。
```

### 生成后定向修复

```text
$commercial-image-reverse-engineer
图1是原产品，图2是生成结果，下面是使用的提示词。
我已认可构图和色调，但瓶盖材质变了。
请对照源图，只写修复瓶盖的增量提示词，保留其他已认可部分。
[粘贴原提示词]
```

## 会得到什么

按需求交付：

1. **简要分析**：产品必须保留什么，参考中哪些方法值得迁移。
2. **画面方案**：卖点如何变成可见的材质、动作和空间关系。
3. **可复制提示词**：明确主体、关系、场景、光影材质、镜头、构图色彩、比例与必要禁项。
4. **关键待确认项**：仅列影响画面的缺失信息，例如开盖结构或准确标签文字。

简单任务可以直接要求“一段提示词”；复杂画面可以要求分模块版本。普通使用不需要填写 JSON 或运行 Python。

拿到提示词后，将产品原图及所需参考一起上传至支持参考图输入的生图工具，按提示词声明图片职责。生成后回传结果，可以继续局部修复。包装文字需要逐字核对，必要时用原产品图合成。

## 案例：娇韵诗兰花油「清润初触」

**任务**：以真实产品照锁定外观，用放大的植物瓣面与薄金油液，表达清润、顺滑、温润的使用联想。金色为主色，超现实尺度结合真实摄影质感。

**设计思路**：产品是视觉中心；植物瓣面在后方舒展，薄油沿凹槽汇聚为一颗油滴，通过透明度、表面张力和透射光表现油的触感。植物形态是创意隐喻，不代表具体配方植物或实际萃取工艺。

### 提示词示例

以下为便于阅读的精简版，保留该案例的主要控制条件：

```text
创作一张娇韵诗兰花面部护理油商业静物主视觉，3:4竖幅。
图1实物照为唯一产品身份依据，保留瓶身比例、圆润瓶肩、
透明厚底玻璃、金黄色油液、浅香槟金色圆柱滴管盖、
白色圆头胶头及正面白色印刷布局。仅一瓶，闭合直立，
正面朝向镜头，去除原照片中的手与生活背景。

产品位于中下部，稳稳站在浅香槟金半哑光台面上，
瓶底有真实接触影。后方一片数倍于产品的半透明植物瓣面
柔和舒展，具有自然纤维、细微脉络和薄透边缘，不遮挡产品。
清透浅金油液沿瓣面凹槽滑落，在侧方下垂尖端汇聚成一颗
将落未落的油滴，与瓶身保持清楚间隔。

右后上方大面积柔光穿透植物、油液与玻璃，左前方弱柔光
照亮包装。玻璃保留厚度与折射，盖子呈细腻金属光泽，
胶头柔和哑光。焦点落在产品正面与瓶肩，后方瓣面随距离
自然柔化。以浅香槟金、明亮植物油金和淡奶白建立色彩层次，
上方适当留白，真实商业摄影质感。

保留可核实的包装文字，不猜写模糊小字；背景不新增广告字、
徽章或水印。避免蜂蜜般拉丝、厚重油池、金属花瓣、
塑料质感与明显CG渲染感，不增加第二瓶或无关配件。
```

## 项目文件与进阶使用

| 位置 | 内容 |
|---|---|
| `.agents/skills/commercial-image-reverse-engineer/SKILL.md` | Skill 主入口 |
| 同目录 `references/` | 摄影、提示词、模型适配与修复说明 |
| 同目录 `assets/` | Brief 与审核记录模板 |
| 同目录 `scripts/` | 结构化 Brief 检查与提示词编译 |
| 同目录 `examples/`、`tests/` | 合成数据与离线回归测试 |

维护者可从仓库根目录运行：

```bash
S=.agents/skills/commercial-image-reverse-engineer
python "$S/scripts/check_skill.py"
python -m unittest discover -s "$S/tests" -v
python "$S/scripts/validate_brief.py" --brief "$S/examples/forest-serum.brief.json"
python "$S/scripts/compile_prompt.py" --brief "$S/examples/forest-serum.brief.json" --out output-demo
```

这些命令检查文件结构、Brief 规则和编译输出；实际画面质量由生成结果判断。Skill 的交付核心是提示词，是否直接生图取决于当前会话连接的工具。
