# 九模块结构化反推提示词

> 文章原始通用公式：任务总纲 + 主体锁定 + 关系定位 + 场景承载 + 光影材质 + 镜头景别 + 构图色彩 + 画质比例 + 反向约束。这里将其转成一致的机器输出骨架。

## 写作原则

同一要点只写在最适合的模块，避免多个段落重复且相互冲突。镜头、比例、景深和光比按本次图像需要设定；与用户商品结构冲突的参考元素一律不继承。不要用“高级、大气、8K”代替光线方向、材质机理和焦点位置。

1. **场景总纲**：任务+视觉创意+场景类型+意图。最多 2–4 句，说明唯一视觉焦点，不重写所有细节。
2. **主体锁定**：对象身份；`外形/材质/部件/状态` 四维，每个零件有确定外观，标注禁变项目；包装文字只复述已确认的字符串。
3. **关系定位**：主体坐标、朝向、前/中/后景、遮挡界限；若置于承载面，写出稳定支撑；若悬浮，明确无实体承载，并写可解释的悬浮姿态、流体接触或投影关系。
4. **场景承载**：背景、实体承载面（或明确无实体承载）、道具数量和功能。每个道具都应服务视觉叙事，避免附着到商品本体。
5. **光影材质**：主光方向+光质；补光/轮廓光的分工；阴影接触；每种材料对应不同反射/折射/粗糙度/纹理细节；不要把“次表面散射”机械地套到所有玻璃。
6. **镜头景别**：焦段是可选创作设定；机位高低、俯仰、景别、透视和锁焦必须逻辑一致。
7. **构图色彩**：主体画面占比指的是约定的尺寸度量（宽度/高度/面积须说明）；留白、视觉主次、主辅色、饱和度、景深、色温协调。
8. **画质比例**：画幅和写实质感、可交付的分辨率目标；不要保证具体工具一定输出 8K/RAW。
9. **反向约束**：从商品不可变形、文字、光向、支撑、材质和脏元素等 3–8 个风险归纳；用受限范围明确“禁止背景额外文字”，不误伤包装品牌。

## 短提示词和长提示词

- 短版供用户确认：一段场景+产品四锁+光源主次+支撑+禁止核心错误。短版不应丢失影响身份的约束。
- 长版供复杂生成：九模块完整，尤其适合带参考图片的生成模式。生成工具提示词限长时首先删抒情形容词，再删重复参数，绝不删“商品身份/禁止错件/接触/文字政策”。
- 原文示例的非常长提示词是**格式示范**，不是最佳长度的实验结论；对模型更稳定不能仅凭字数推断。

## 防冲突预检

- `preserve label` 与 `no text, no logo` 全画面禁令冲突。
- `support_type=suspended` 与 `落在石台并有接触影` 冲突。
- `侧逆光为唯一主光` 与 `完全均匀正面平光` 冲突。
- `忠实原产品` 与 `参考图相同瓶盖/图二品牌` 冲突。
- `图中没有人物` 与 `室内人物真实摄影` 冲突。
- `精确还原字体` 但字无法辨认：不允许编造，需标记待修。

## 中英双语

默认中文；用户明确要求英文时，先确认中文规格不丢字段，再以相同的模块结构翻译。翻译不应新增产品事实；商品上的印刷字符串不翻译。
