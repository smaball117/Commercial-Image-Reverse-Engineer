# 失败排查 → 单变量修复

失败后先确定最严重的真实症状，引用原 brief 中的硬锁，选 1 个最相关控制字段修改，保留其它已被认可的维度。

| 症状 | 可能缺失 | 单变量修复方向 | 需验证 |
|---|---|---|---|
| 瓶盖材质/轮廓改变 | 主体四锁不具体 | 指明盖的几何、颜色、材料及不可从参考继承 | 比对源图的盖子轮廓 |
| 产品悬浮像P上去 | 关系定位/接触影缺失 | 仅加强支点、接触边缘和环境反光；不改场景 | 物体底部与台面接触 |
| 产品在应悬浮场景被放上底座 | 模式混淆 | `support_type=suspended` 明写无实体承载 | 没有额外台面 |
| 玻璃变亮塑料/浑浊 | 材质光学描述失准 | 只修复粗糙度、透光、反射形状 | 对比图中高光和透明层 |
| 文字乱码/缺失 | 生成模型文字上限 | 先锁标签位置与大字；无法保证时保留原产品/后期贴字 | 按业务字样核对，不靠猜 |
| 商标被道具挡住 | 前景遮挡界线未写 | 指定道具不得越过标签安全区 | 标识完整可读 |
| 背景太花/主体小 | 焦点层级失衡 | 只降低背景复杂度或调整尺度 | 主体成为第一识别对象 |
| 光影发平 | 主/辅光缺分工 | 明确主光方向、补光相对强度与暗部梯度 | 受光面/背光面有体积 |
| 多了麻绳/木牌 | 错把参考道具迁移 | 不继承参考附加件且仅保留来源商品部件 | 无新增配件 |
| 人手数量错误/握持怪 | 人体接触约束缺失 | 追加手指/握持位置/关节结构（拓展模式） | 手部与产品可握持 |

## 修改记录规范

`iteration-xx`: `failure -> suspected cause -> field_changed -> prompt_delta -> unchanged_locks -> visual_result -> decision`。如果一次只改一变量仍失败，可以升级为换生成策略：高保真局部编辑、先抠产品再统一布光和阴影、人工替换包装文字。不要以反复随机采样替代问题定位。
