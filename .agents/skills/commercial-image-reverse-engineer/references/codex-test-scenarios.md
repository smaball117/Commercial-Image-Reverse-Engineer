# Codex 行为验收剧本（用户可复制）

以下是将来由 Codex 在真实任务中执行的**检查用例**。未实际运行的视觉/模型任务，不可标记为 PASS。

## T1：单图只反推

**输入**：仅附一张产品摄影参考图。“反推这张图的布光、构图、质感”。

**期待**：输出真实可见的光影结构、主体与背景层次、材质受光、可迁移关键词；不声称看见了不存在的图2，不要求凭空构造其他商品的商标。

## T2：商品身份和参考分离

**输入**：图1是实际商品，图2是不同品牌的广告。“参考图2做场景”。

**期待**：图1产品四锁、图2摄影语言迁移，禁止换瓶盖、包装/Logo、参考图额外道具。

## T3：精确包装字

**输入**：用户明确提供 "ABC LAB" 和 "30 mL"。

**期待**：标签 `preserve`，提示词只禁止背景额外文字；不出现全画面“no logo/no text”。

## T4：标签字看不清

**输入**：源图模糊，商品正面细字不清楚。

**期待**：`unverified`；不猜字；建议原标签后期精准合成，不能宣称最终商业字已经精确。

## T5：物理实体承托

**输入**：“瓶子站在松枝上”，参考图主体像悬浮。

**期待**：采用图1和用户要求的实体承托关系，定义支撑面、接触边、接触影；不同时写自由悬浮。

## T6：流体悬浮

**输入**：“瓶子悬浮在水带中，无实体底座”。

**期待**：不出现树枝、台面、地面接触影；水流前后空间层次与主体材料一致。

## T7：结果图单变量修复

**输入**：新生成图构图已正确，但瓶盖从白色塑料变成银色金属。

**期待**：只提供瓶盖的定向修复指令，明确背景、机位、光色、人物（若有）、主体位置不变；不从头设计一张广告图。

## T8：参数是建议而非测量

**输入**：参考图没有 EXIF。“告诉我这张图精准的焦段、光比和占比”。

**期待**：说明无法从单图准确测量，提供适合重建视觉的建议区间或可控描述，明确不是图片实测参数。

## 测试报告

复制本节给 Codex，要求它逐项输出：`TestID / 输入附件是否可见 / 路由模式 / 结果摘要 / PASS-FAIL-NOT_VERIFIED / 证据 / 必要修复`。真实图像生成只能在使用对应生图模型以后评价；不能用文案逻辑检查替代。
