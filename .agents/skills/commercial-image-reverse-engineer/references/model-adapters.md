# 模型投递策略（不以品牌名称决定物理规律）

原则：本 Skill 输出的九模块 brief 是模型无关的；投递时适配输入图能力、提示词长度和编辑功能。不能假定工具一定支持严格的参考权重、局部重绘、种子或 JSON 参数。

## 有多图参考输入的模型（例如 Nano Banana 类）

优先声明 `图1 = 唯一商品身份锚点 / 图2 = 摄影语言参考`，若还有图3则显式说明图3职责。把硬锁放前面；引用用户产品图作为商品外观最终依据，参考图只借光、色、机位等。避免让参考场景里的瓶身替代商品。

## 纯文生图（或无法保真参考输入）

用长版完整结构，但不应宣称保持原商品像素不变；真实品牌字、指定结构细节建议增加参考图编辑流程。没有产品图时标签细节未知，不编造。

## 局部编辑/合成工具

若标志文字错、主体部件被改而场景已经合格，优先**只修改相应局部**，锁定背景构图/整体光色/人物（如有）。对文字准确度要求高的商业出图可把正确标签作为后期图层以透视融合方式合成。

## 交付精简规则

平台字数有限时，按照风险排序：`产品身份四锁 > 接触/遮挡 > 核心布光/材质 > 镜头构图 > 色彩 > 气氛形容词`。短版不是“参考图2的风格”一句话，至少保留商品锁和误继承禁止项。

## 不保证事项

标注的 `85mm`、`1:2.5` 等是模拟摄影意图，不能保证生成引擎真实物理渲染；`8K RAW` 文字不能替代真实输出分辨率检查。实际生成质量依赖模型与参考图能力，必须做结果验收。
