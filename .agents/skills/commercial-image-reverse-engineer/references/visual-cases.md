## 原文方法与本 Skill 的区别

- **原文明确支持**：主体外形/材质/部件/状态四锁；关系定位；支撑接触；主补光与材质受光；镜头、构图、色彩、反向约束；以及松枝、岩洞、流体等视觉实例。
- **本 Skill 的工程扩展**：机器可读输入 brief、来源置信状态、冲突检查脚本、分级硬门槛、工具无关的提示词编译、失败 A/B 记录。这些是设计补充，不是原作者已实现或验证的代码。
- **关于效果**：原作者提供了个人案例和体验，没有提供足以说明“稳定输出概率”或跨模型成功率的统计实验。要宣称模型有效，必须另行用用户真实素材做盲测/复测。

## 可复制的评估方案

对同一组商品图、参考图、模型版本与固定参数，比较 baseline（仅“图1商品、参考图2风格”）与 Skill 输出各至少 3 次生成。记录商品身份、结构、文字、材质、接触、摄影感、主次、伪影，不只挑最好的 1 张。首轮验证是定性小样，不是统计证明。
