# 真实模型验证方案（由 Codex 与用户执行）

这个文件是**将来测试的计划**，不包含已完成真实视觉测试的结论。

## 对照分组

- **A 基线**：用户商品图 + 参考图 + 简短描述“图1是我的产品，参考图2风格，产品不变”。
- **B Skill**：完全相同商品图、参考图、模型、版本、画幅、尺寸、输入数量、随机种子（若可用），仅换成已编译的受控 Prompt。
- 不强制声明所有工具可提供固定 seed 或真实参考权重。不能控制的设置须记录。
- 三个场景至少各 3 个 A/B 配对，初步 18 张结果；用于探索而非统计显著性结论。

## 三类用例

1. **实体承载**：单瓶置于自然树枝/岩石。核心检查接触、瓶身、材质与文本清晰。
2. **明确悬浮/流体**：产品悬浮且与水流交织。核心检查体积、流体前后关系、标签不被挡。
3. **包装字准确**：高精度品牌与净含量测试。应把可编辑合成列为备选；不把生成模型未能印对商标算通过。

## 记录模板

| 字段 | 解释 |
|---|---|
| Case ID / 日期 | 确保不同图对应不同测试 |
| 输入图片 SHA 或实际文件名 | 文件可追溯，隐私图不公开 |
| 模型和具体版本 | 工具版本、是否开启参考图 |
| Prompt 版本 | A/B 原文和 Skill 编译版本 |
| 固定与变化项 | 仅改变 prompt 或说明例外 |
| 输出件数 | 不能只保留满意的一张 |
| 硬门槛 | H1–H5 PASS / FAIL / NOT_VERIFIED |
| 软评分 | 5 项各 0–2，总分 10 |
| 用户感受和失败点 | 记录未被模型修复的核心问题 |
| 下次改动 | 一轮只改一个变量 |

## 验收策略

- 有任一硬门槛 FAIL，商业正式交付即 FAIL；未知不能假定通过。
- 对软评分趋势进行配对对比，计算合格率要使用**全部出图分母**，不可挑最好图。
- 如果多个模型表现相反，保留型号相关证据，而非宣布某条提示词“ universally best”。
- 只将被多次验证且知道适用边界的经验加入通用规则；未验证仍保留为实验备注。
